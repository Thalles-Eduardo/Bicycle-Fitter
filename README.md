# 🚴 Bike Configurator

An immersive high-performance bike configurator built with modern web technologies, focused on fluid interactions, cinematic animations, and premium UI/UX.

---

## ✨ Preview

> A fully animated bike customization experience with dynamic transitions, persistent state management, and smooth page interactions.

🎥 Demo video included in the repository.

---

# 🖼 Features

- ⚡ Smooth page transitions with GSAP
- 🎨 Modern and premium UI design
- 🚴 Dynamic wheel selection system
- 🛠 Dynamic frame customization
- 💾 Persistent configuration using Zustand
- ✨ Advanced GSAP animations
- 📱 Fully responsive layout
- 🚀 Built with Next.js App Router
- 🧠 Optimized asset preloading system
- 🔥 Interactive hover animations
- 🎬 Cinematic entrance transitions

---

# 🛠 Technologies

- Next.js 15
- React
- TypeScript
- TailwindCSS
- GSAP
- Zustand
